# Uganda Agro-Zone Seasons

How the rainy seasons of Uganda's agro-ecological zones changed from 1981 to 2025: when the rains start and end, season length, dry spells inside the season, rain per rainy day and heavy-rain days.

Live page: https://muhire-taa.github.io/uganda-agrozone-seasons/

## Data

- Rainfall: CHIRPS daily rainfall (Climate Hazards Center, UC Santa Barbara), averaged over each zone by SERVIR ClimateSERV.
- Zones: built from the FEWS NET Uganda livelihood zones (2013), grouped into Uganda's ten-zone agro-ecological scheme, with the Mt Elgon highlands kept separate.
- Temperature: ERA5 reanalysis (ECMWF) via the Open-Meteo archive.

The tables behind every chart are in `data/`.
